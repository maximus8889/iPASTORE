# iPAStore 1.0.0 Build 152

From build 151, open Settings → iPAStore Updates → Check for Updates, then select View Latest Release. Download `iPAStore.ipa` from the release assets or use the [iPAStore download page](https://maximus8889.github.io/iPAStore/install.html).

Install over your existing copy with the same signer, signing team, and bundle identifier to retain your apps and data. Keep your current installation in place while updating. The website setup profile adds the download page to your Home Screen. The IPA requires valid signing and provisioning.

## Changes

- Save and switch between multiple standalone signing certificates. Each certificate keeps its own provisioning profile.
- Choose from more fonts and icons, customize success sounds and haptics, and choose the subtitle shown for installed apps.
- Browse categorized libraries, use the shared All Apps page, and keep Get or Open within reach while scrolling an app page.
- See download time estimates, check for updates to installed apps, and download selected updates or all eligible updates.
- Use consolidated Apps and Stores menus, consistent search, quieter tab transitions, a redesigned game return screen, and updated expiration widgets.
- Check the installed build against the latest compatible GitHub release and download a newer IPA from Updates.

The verification attachment records the package and build checks. This candidate still needs an in-place update and signing test on a physical iPhone.
